# Completed YuE2 Native60 frozen transfer

276 length-eligible recordings: 223 development and 53 previously locked.
3,175 stored model applications, no fitting or threshold tuning. All 876,300
predictions were checked with a scalar implementation of the saved model and
reconciled to the persisted summaries. This report contains all 1,905 aggregate
subset/cap/population cells, not only the combinations shown in the thesis.

Every population is AI-only. Reported sensitivity is not binary accuracy,
balanced accuracy, specificity or ROC AUC. The historical seven families are
S/D/R/P/F/H/M; M-containing subsets are secondary diagnostics, not SC/BC models.
These recordings are duration-selected and not a new independent acquisition.

The package COMMIT binds the generated CSV and LaTeX table, and identifies the
original scoring COMMIT. This explanatory README was added for repository
publication and is not a product listed in that original report COMMIT.

Full predictions, intermediate outputs and thesis v6 are preserved locally in
`Documents/report/music_ai_detection_20260912/`. Source-audio publication is
still being reconciled separately; this report does not certify full delivery.
