# YuE derived-audio independent acceptance

At public dataset revision `caed9220f68b258e9c2dcb89792ccb1fe4d1dc61`,
all 5,900 unique audio objects in the seven-directory YuE plan passed anonymous
verification: exact manifests and notices, and every LFS SHA-256 and size.
This comprises 4,900 additional objects and 1,000 legacy Demucs objects,
56,849,461,990 bytes and 6,922 source-path memberships. These are versions of
500 generated recordings, not 5,900 independent songs.

The terminal record, independent acceptance, manifest and 98 batch receipts
are preserved here. See `../yue_derived_publication_plan_v1/` for the immutable
object and membership plans. Its pre-publication flags are historical; this
acceptance supplies subsequent verification rather than rewriting that plan.

No full audio redownload was performed. This verifies only the seven inventoried
YuE directories, not every historical project input or non-YuE derivative.
Whole-project publication and rights reconciliation remain incomplete.
