# SALAMI original-recording terms checkpoint

44 Internet Archive item metadata endpoints were queried for the 44 preserved
external-test tracks. 43 responses were retrieved and each matched the exact
source filename; one request failed. None of the 43 retrieved items supplied
an explicit licenseurl value. Metadata response hashes, available rights/usage
fields, artist information and selected-file checksums are retained in records.

This absence is not proof that redistribution is forbidden. It means a public
audio release is not established by this evidence. Artist/collection policies
or explicit authorization may supply additional evidence. SALAMI annotation
licensing is not a substitute for recording licensing. No audio was uploaded.

Each record links its authoritative https://archive.org/download/ source;
metadata was fetched from https://archive.org/metadata/<identifier>. The fresh
source-byte audit is separately pinned in COMMIT.json. One failed request must
not be represented as a successful license check.
