# Selected DEAM attribution recovery

All 300 historical selected IDs match official DEAM metadata uniquely, with
nonempty artist and title fields. Source audio hashes remain bound to the
existing diversity catalogue; no audio, labels or experimental grouping changed.
The complete official metadata ZIP is retained locally in the parent directory,
not republished here. Only the 300 selected attribution records are included.

Source: https://cvml.unige.ch/databases/DEAM/metadata.zip
Dataset: https://cvml.unige.ch/databases/DEAM/
Manual: https://cvml.unige.ch/databases/DEAM/manual.pdf
Authors: Mohammad Soleymani, Anna Aljanaki and Yi-Hsuan Yang.

The official page describes Creative Commons audio, and the manual identifies
FMA, Jamendo and MedleyDB as sources. Neither this recovered metadata nor the
manual establishes an exact per-track license. Artist attribution is now
recovered; individual audio republication remains unverified. Do not infer a
uniform recording license from dataset availability or annotation terms.

COMMIT.json binds both inputs and recovered records. No lyrics, folksonomy tags
or source audio were exported. Full historical source roles remain unchanged.
