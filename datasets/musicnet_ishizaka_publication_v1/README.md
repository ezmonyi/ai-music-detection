# MusicNet Ishizaka publication acceptance

All 39 selected MusicNet recordings attributed to Kimiko Ishizaka are published
at revision `587537ec4bc1d60750f05b4fc6c7dccb71d5e70c` of
[the public audio dataset](https://huggingface.co/datasets/EZMONYI/music-ai-human-test-audio/tree/587537ec4bc1d60750f05b4fc6c7dccb71d5e70c/audio/musicnet_ishizaka_cc0_v1).
They contain 862,136,022 bytes. These are existing human-source records, not a
new independent test population.

`INDEPENDENT_ACCEPTANCE.json` records anonymous fixed-revision verification of
the exact manifest and notice, source-record bindings, and all 39 LFS SHA-256
hashes and sizes. This is not a complete audio redownload. `manifest.json` and
`COMMIT.json` preserve the publisher's exact object inventory and terminal state.

The official MusicNet metadata maps these selections to Ishizaka's Well-Tempered
Clavier Book 1 recordings; the artist's
[album page](https://kimikoishizaka.bandcamp.com/album/bach-well-tempered-clavier-book-1)
states CC0 for the recording. No byte identity with the separate high-resolution
album download is claimed. The other 291 MusicNet selections are not cleared by
this acceptance. Whole-project publication remains incomplete.
