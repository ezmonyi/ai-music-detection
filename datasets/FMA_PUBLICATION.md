# FMA source-audio publication checkpoint

392 unchanged FMA medium MP3s from the 500 historically tested FMA IDs are
published with per-track authors, titles and explicit license versions:

https://huggingface.co/datasets/EZMONYI/music-ai-human-test-audio/tree/1bee1265384dc069ad6d1247c0ae7bfd9db09761/fma_originals_explicit_license_v1

394 files (392 audio, README, manifest) were verified against remote size and
content hashes at that revision. Each original MP3 was rehashed and matched to
the historical input hash; the track and artist IDs were joined to the retained
FMA metadata. No signal transformation was performed for this publication.

These are the FMA medium distribution's approximately 30-second excerpts, not
full-length originals. Each recording retains its own CC/CC0 terms, including
NC, SA or ND where stated. No blanket license overrides those terms. ND files
are shared unchanged; derivatives are not included or cleared by this release.
108 additional selected recordings remain excluded because their license labels
were not mapped unambiguously. The HF manifest preserves their IDs and reasons.

This checkpoint does not include all tested derivatives or all project sources.

`2aae3374be02122ce65874a64bb5bb8996403965a23613c22d01c02f15350ccc`;
it remains local/server-side because it contains server filesystem paths.
