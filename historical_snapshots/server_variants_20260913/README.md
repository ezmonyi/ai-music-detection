# Preserved server variants — 2026-09-13

These two Python files were retrieved from the YuE extension server directory
after a read-only SHA-256 audit found their bytes absent from the repository's
current and historical Python files. Existing local versions are not replaced.
Both files were inspected before publication; they contain no embedded access
credentials. They are archival source variants, not new experiment results.

Audit scope: 392 local expanded-phenomena Python files and 206 local top-level
YuE extension Python files all had byte-identical repository counterparts.
The server contained 392 expanded-phenomena Python files and 141 top-level YuE
extension Python files. Exactly two server byte variants were initially absent;
this directory preserves them. Other historical server directories remain
outside this audit. No claim of whole-project code completeness is made.
